# 换一台电脑继续开发

这套系统没有任何云依赖：后端 FastAPI + SQLite 单文件、前端 Vue3 + Vite，拷走文件夹就能跑。

## 一、要带走什么

整个 `daimon-mes` 文件夹。可以只带源码（体积约 60KB）：

```
daimon-mes-src.tar.gz      ← 已排除 node_modules / .venv / dist
```

**但 `backend/mes.db` 必须单独确认**：它是全部数据（账号、工单、SN、过站记录、箱单）。
源码包里默认不含它，如果新电脑要继续用老数据，把 `backend\mes.db` 一起拷过去。

## 二、新电脑需要装什么

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | 3.11+ | 安装时勾选 Add Python to PATH |
| Node.js | 18+ | 自带 npm |

不用装数据库、不用装 Docker。

## 三、三步跑起来

1. 解压 / 拷贝 `daimon-mes` 到任意目录（路径别带特殊符号）
2. 双击 `启动.bat` —— 首次会自动建虚拟环境、装依赖（1～2 分钟）
3. 浏览器打开 `http://127.0.0.1:5173/login`

账号 `admin`，密码 `123456`（存在 `mes.db` 里，换机不变）。

## 四、手机接入

- 后端监听 `0.0.0.0:8007`，手机与电脑同一 WiFi 时访问 `http://电脑局域网IP:8007/login`
- `手机扫码入口.html` 里有二维码；**换了电脑或换了网络，IP 会变**，需要重新生成这个页面
- 手机浏览器「添加到主屏幕」后会像 App 一样全屏打开（已配 manifest）

## 五、目录结构

```
daimon-mes/
├─ backend/
│  ├─ app/main.py       API 与业务状态机（登录/工单/SN导入/过站/返修/装箱/查询）
│  ├─ app/models.py     7 张表的 ORM 定义
│  ├─ app/schemas.py    请求/响应模型
│  ├─ requirements.txt
│  └─ mes.db            数据（要带走的）
├─ frontend/
│  ├─ src/views/        5 个页面：Login / WO / Station / Pack / Query
│  ├─ src/style.css     品牌样式与登录页 HUD
│  └─ vite.config.ts    开发代理 /api → 8007
├─ 启动.bat
├─ 手机扫码入口.html
└─ 换机开发说明.md
```

## 六、换数据库（可选）

`DB_URL` 环境变量改一行即可切 PostgreSQL，ORM 层不用动：

```
set MES_DB_URL=postgresql+psycopg://user:pass@host:5432/mes
```
