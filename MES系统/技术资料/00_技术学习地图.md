## 1. Python FastAPI（后端框架）

| 资源 | 地址 |
|---|---|
| 官方中文文档 | https://fastapi.org.cn/zh/ |
| 官方教程·SQL 数据库 | https://fastapi.tiangolo.com/zh/tutorial/sql-databases/ |
| 本项目代码 | `backend/app/main.py` |

**先看这几处**：
- `app = FastAPI(...)` 与 `app.add_middleware(CORSMiddleware...)` —— 应用初始化与跨域
- `@app.post("/api/login")` —— 一个最简单的 POST 接口
- `def get_db()` + `db: Session = Depends(get_db)` —— **依赖注入**，FastAPI 核心概念
- `require_auth()` —— 用 Header 做登录校验
- `http://127.0.0.1:8007/docs` —— 自动生成的接口文档，边看边点

**为什么选它**：类型注解即校验，自动生成 API 文档，省掉手写接口文档的时间。

## 2. SQLAlchemy（ORM / 数据模型）

| 资源 | 地址 |
|---|---|
| 官方 ORM 教程（中文镜像） | https://www.osgeo.cn/sqlalchemy/orm/tutorial.html |
| FastAPI + SQLAlchemy 集成教程 | https://www.pydocs.cn/chapter/0FD384B4377CE933880C2EA180EA79A6.html |
| 本项目代码 | `backend/app/models.py` |

**先看这几处**：
- `Base = declarative_base()` —— 所有模型的基类
- `class WorkOrder(Base)` —— 工单表；注意 `stations = Column(JSON)` 存站点数组
- `relationship("Unit", back_populates="wo")` —— 工单与 SN 的一对多关系
- `StationRecord.unit_id` —— **引用式关联**（借鉴 KTG 的 source_doc_id 思路）

**关键理解**：ORM 让你用 Python 对象操作数据库，不写裸 SQL。因此将来把 `DB_URL` 从 `sqlite:///./mes.db` 改成 `postgresql://...`，业务代码几乎不用改——这就是"平滑迁移路径"的实现方式。

## 核心概念速查

| 概念 | 一句话 | 本项目位置 |
|---|---|---|
| 依赖注入 | 框架自动把资源（数据库连接）传给函数 | `Depends(get_db)` |
| ORM | 用对象操作数据库，屏蔽 SQL 方言差异 | `models.py` |
| 状态机校验 | 服务端校验流转合法性，防跳站 | `main.py` 的 `station()` |
| 幂等 | 重复提交只生效一次 | `station()` 里检查 `body.station in done` |
| 事务 | 一组操作全成功或全回滚 | `db.commit()` / 异常时回滚 |
| 乐观锁 | 用版本号检测并发冲突 | `WorkOrder.rev` 字段（V1 已建字段，V1.1 启用校验） |
| 响应式 | 数据变了界面自动更新 | `ref()` / `computed()` |
| 单文件组件 | HTML+CSS+JS 写在一个 .vue | `views/*.vue` |
