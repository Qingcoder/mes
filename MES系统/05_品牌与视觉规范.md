# 戴盟 MES 生产管理平台 · 品牌与视觉规范

> 文档编号：05
> 建立日期：2026-11-19
> 用途：架构源文件，供 AI 转化为前端界面 / 原型 / 交付物时遵循
> 适用项目：戴盟 MES 生产管理平台（内部代号 mes-greenfield）

---

## 1. 品牌身份

| 项 | 内容 |
|---|---|
| 平台名称 | **戴盟 MES 生产管理平台** |
| 公司全称 | 戴盟（深圳）机器人科技有限公司 |
| 英文名 | Daimon Robotics |
| 官网 | https://www.dmrobot.com |
| 行业 | 机器人 · 多模态触觉感知 · 具身智能 |

**品牌内核**（来自官网与品牌设计方公开资料）：
- 使命：感触世界，创造无限生产力
- 定位：以触觉感知与灵巧操作为核心，穿戴式遥操作数据采集系统
- 平台产品覆盖：三代遥操、V2.5 / V2.9 无本体数采背包与夹爪——即本 MES 要管理的生产对象

## 2. 主色：中国红

**品牌色选用中国红**，这是一项刻意的差异化策略——**打破机器人行业惯用的科技蓝**，显著提升辨识度。

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 primary | `#E61736` | 取自官方系统 CSS 变量 `--red` 与 logo 填充色 |
| 浅底 soft | `#FDECEA` | 取自 `--red-soft`，用于选中态、标签底 |
| 深红 hover | `#BC122F` | 主按钮悬停态（沿用官方系统用法） |

**落地纪律**：
- 主色用于：品牌标识、主按钮、当前选中项、关键数据强调、状态高亮
- 禁用科技蓝做主色——蓝只作辅助信息色（链接、次要提示）
- 主色面积克制：界面主色占比建议 ≤ 20%，大面积留白/浅灰底

## 3. Logo 规范

**设计理念**（品牌设计方公开说明）：
- 以英文名首字母 **D** 为核心视觉符号，拆解为**三段相连**的结构
- 右侧开口形如**灵巧手指即将触碰的瞬间**，传达触觉感知的技术基因
- 整体轮廓**融合方与圆**，象征立足触觉与灵巧操作、向具身智能拓展
- 用中国红，区别于行业科技蓝

**技术资产**：
- 官方系统内嵌的 logo SVG：`viewBox="0 0 464.45 157.58"`，含两色 `#E61736`（主）与 `#484C4E`（灰）
- 位置：`mes-custom/source/index.html` 中的 `.dm-logo` 节点——可直接提取复用，**这是官方视觉资产，不是自绘**
- 提取方式：从该节点复制 `<svg>...</svg>` 整段，勿重画、勿改路径

**使用规则**：
- 登录页、侧栏品牌区使用完整 logo
- 单色小尺寸场景（favicon、表格角标）可用红色 D 图形
- 不拉伸变形、不改填充色、不加描边阴影

## 4. 中性色与界面色板

以下取自官方系统 `:root` 变量，保持与既有平台观感一致：

| 语义 | 变量 | 色值 |
|---|---|---|
| 主文字 | `--ink` | `#2B2E31` |
| 次文字 | `--gray` | `#484B4E` |
| 弱文字 | `--muted` | `#8C9199` |
| 描边 | `--line` | `#E6E8EB` |
| 页面底 | `--bg` | `#F4F5F7` |
| 卡片底 | `--white` | `#FFFFFF` |
| 成功 | `--green` | `#1A7A4C`（浅底 `#E8F4EE`） |
| 警示 | `--amber` | `#C77700`（浅底 `#FFF3E2`） |
| 信息 | `--blue` | `#2B6CB0`（浅底 `#EAF2FA`） |

**语义色用途**：过站通过用绿、不良用红、待检用琥珀——与 SN 状态机一一对应。

## 5. 字体与排版

- 中文：`Microsoft YaHei` / `PingFang SC`（沿用官方系统字体栈）
- 西文与数字：`Helvetica Neue`, `Arial`
- 字号层级（参照官方系统）：页面主标 19–23px、卡片标题 16px、正文 15–16px、辅助 13–14px
- 数字与 SN 码建议等宽字体（`Consolas` / `Menlo`），便于核对

## 6. 视觉母题

- 侧栏宽 352px，固定定位，白底右侧 1px 描边
- 顶栏高 68px，白底、 sticky
- 卡片圆角 6px，轻阴影 `0 1px 3px rgba(30,34,40,.06), 0 6px 18px rgba(30,34,40,.04)`
- 选中态：主色红底白字；常态：白底灰字、hover 浅灰

## 7. 给 AI 的转化约束

生成前端界面 / 原型 / 交付物时必须遵守：

1. **主色只能是中国红 `#E61736`**，不得替换为科技蓝或渐变紫
2. **logo 用官方 SVG 原样**，从 `mes-custom/source/index.html` 的 `.dm-logo` 节点提取
3. 平台名称统一为"**戴盟 MES 生产管理平台**"，不写"戴盟智造数字化管理平台"（那是参照系统名）
4. 沿用第 4 节色板与第 5 节字体栈，不引入新配色体系
5. 状态色与 SN 状态机对应：通过=绿、不良=红、待检=琥珀
